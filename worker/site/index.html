日本の住所を、座標と地域コードに変える

住所を渡すと、緯度・経度と市区町村コード、国勢調査の小地域コード、郵便番号、地域メッシュを返します。地図上の点から市区町村と小地域を引くこともできます。登録なしで、無料で使えます（ベータ）。

試す

地図をクリックすると、その点の市区町村と小地域のコードを出します。

一括変換

住所の列がある CSV を選ぶと、右に座標とコードの列を足したファイルを作ります。1 ファイル 1,000 行まで。ファイルはこのページの中で読み、住所の文字だけを API に送ります。ファイルそのものはどこにも保存しません。

API

curl -s -G https://geocoder.queria.io/v1/geocode \
  --data-urlencode "address=東京都千代田区紀尾井町1-3" \
  --data-urlencode "include=codes,small_area"
  • 住所から引く: GET /v1/geocode?address=…。住所は URL エンコードして渡します
  • まとめて引く: POST /v1/batch（1 回 100 件まで）
  • 座標から引く: GET /v1/reverse?lat=…&lng=…
  • include で項目を足し、format で json・geojson・csv を選べます。項目名は abr-geocoder（デジタル庁）と同じです
  • 1 つの IP から 1 分に 300 回まで。超えると 429 を返します

項目ごとの説明は 仕様書 にあります。

答えの見方

  • match_level は住所がどこまで当たったか、coordinates_level は座標をどの点から取ったかです。号まで当たっても、その号に座標が無ければ町字の代表点を返し、coordinates_level が町字になります
  • 座標はどれも代表点で、建物の位置ではありません
  • 地番の住所は今は町字まで当たります。地番ごとの座標は準備中です
