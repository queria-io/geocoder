日本の住所を緯度・経度に変えるジオコーダーです

地図で押した場所の住所を調べることもできます。住所の列がある CSV は、まとめて変換できます。無料で、登録はいりません。

地図の上を押すと、その場所の住所を出します。

住所の列がある CSV を選ぶと、緯度・経度と地域コードの列を足したファイルを作ります。1 回に 1,000 行まで変換できます。

結果を保存する

ファイルはこのページの中で読み、住所の文字だけを変換のために送ります。ファイルそのものは送りません。

使いみち

  • 顧客の住所録を地図に置く

    会員や取引先の住所を緯度・経度に変えれば、どの地域に多いかが地図で見えます。

  • 出店の候補地のまわりを調べる

    候補地の住所から小地域コードが分かるので、国勢調査の人口と結べます。Queria のエリア分析でそのまま商圏を見られます。

  • 住所の書き方をそろえる

    「1-3」「1丁目3番」のような書き方の違いを、国の住所データの表記にそろえて返します。

  • 地図の場所の住所とコードを調べる

    現地で取った位置や写真の位置から、住所と市区町村コード・小地域コードを出します。

仕組み

デジタル庁のアドレス・ベース・レジストリ（国の住所データ）を毎月取り込み、住所を探すための表を作っています。住所を受け取ると、まず都道府県と市区町村を読み取り、その市区町村の町名・番地の表だけを読んで当てます。返すのは、当たった町名や番地の代表の点の緯度・経度です。

「1-3」と「1丁目3番」、旧字体と新字体のような書き方の違いは、当てる前にそろえます。地図から住所を調べるときは、押した場所にいちばん近い番地の点を探します。

無料で使える理由

サーバーもデータベースも持たず、Queria が整備しているデータをファイルとして置いているだけなので、動かすのにほとんどお金がかからないからです。

  • 国の住所データや統計の境界データを取り込んで直す作業は Queria のデータカタログと共通なので、ジオコーダーのためだけに増える手間はわずかです。同じ表は Queria で誰でも見られます。
  • データベースを持っていません。住所の表は、Cloudflare R2 というファイル置き場にファイルとして置いてあります。
  • 常に動かしているサーバーがありません。問い合わせが来たときだけ、Cloudflare Workers の上でプログラムが動きます。
  • 1 件ごとに読むのは、ファイルのうちその市区町村の部分だけです。全国分を読むことはありません。

この費用は Queria が持ちます。Queria は、その場所の人口や地価などを付けて使う法人向けの契約で収入を得ています。住所から緯度・経度と地域コードを調べる部分は、無料で出す方針です。

答えを信頼できる理由

  • 国が作った住所のデータが元です答えには毎回、どのデータから出したかと、そのデータの日付が付きます。
  • 分からなかったところは、分からなかったと返します町名までしか分からなかった住所は、町名までと分かる形で返します。番地まで分かったように見せることはしません。
  • 作り方を公開していますプログラムを公開しているので、住所をどう当てているかを誰でも確かめられます。
  • 住所録のファイルは送りませんファイルはこのページの中で読み、住所の文字だけを変換のために送ります。

どこまで分かるか

  • 番・号まで住居表示の住所（「○丁目○番○号」）は、その建物のあたりの点を返します。
  • 町名・丁目まで番号が分からない住所や、番号の点が無い住所は、町名・丁目の代表の点を返します。数百 m ずれることがあります。
  • 地番の住所今は町名まで分かります。地番ごとの点は準備中です。

地図から住所を調べるときは、押した場所にいちばん近い点の住所を返します。町名の境目の近くでは、となりの町名になることがあります。

料金

今は無料です（ベータ）。1 つの場所から 1 分に 300 回まで、ファイルの変換は 1 回 1,000 行までにしています。もっと多く使いたいとき、人口や地価などもまとめて付けたいときはお問い合わせください。

開発者の方へ

同じことを API で呼べます。登録も鍵もいりません。

curl -s -G https://geocoder.queria.io/v1/geocode \
  --data-urlencode "address=東京都千代田区紀尾井町1-3"
  • 住所から: GET /v1/geocode?address=…（住所は URL エンコードして渡す）
  • まとめて: POST /v1/batch（1 回 25 件まで）
  • 座標から: GET /v1/reverse?lat=…&lng=…&include=address
  • include で項目を足し、format で json・geojson・csv を選べます。項目名は abr-geocoder（デジタル庁）と同じです
  • 1 つの IP から 1 分に 300 回まで。超えると 429 を返します

項目ごとの説明は API の仕様書 にあります。

出典

結果を載せるときは、答えに付いている出典も一緒に載せてください。

  • 「アドレス・ベース・レジストリ」（デジタル庁）を加工して作成
