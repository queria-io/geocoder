# Excel

[`geocode.pq`](geocode.pq) は Power Query のクエリで、住所の列があるテーブルに、緯度・経度と地域コードの列を足す。Windows と Mac の Microsoft 365 の Excel で使える。

## 使い方

1. 住所の表を選び、「挿入」→「テーブル」でテーブルにする。テーブル名を「住所」、住所の列名を「住所」にする
2. 「データ」→「データの取得」→「その他のデータソースから」→「空のクエリ」を開く
3. 「詳細エディター」に [`geocode.pq`](geocode.pq) の中身を貼り付けて「完了」を押し、「閉じて読み込む」を押す
4. 初回は接続の確認が出るので、`https://geocoder.queria.io` への匿名アクセスを許可する

住所を足したり直したりしたら、「データ」→「すべて更新」を押す。

## 結果

元のテーブルのすべての列に、次の列を足したテーブルが新しいシートにできる。行の順は元のテーブルと同じ。

| 列 | 内容 |
|---|---|
| 緯度・経度 | 代表点の座標 |
| 照合レベル | 住所をどこまで照合できたか（`rsdtdsp_rsdt` は号、`rsdtdsp_blk` は街区、`parcel` は地番、`machiaza` は町字、`city` は市区町村） |
| 全国地方公共団体コード | 6 桁（検査数字つき） |
| 町字ID | アドレス・ベース・レジストリの町字 ID |
| 郵便番号 | 7 桁 |
| 小地域コード | 国勢調査の小地域コード |

- 空の行と、照合できない住所は、足した列が空になる
- 市区町村名のない住所で、同じ町名の市区町村が複数あるときは、先頭の候補（番地まで照合できた候補、次に人口の多い市区町村）を返す

## 回数の上限

API を 25 行ずつまとめて呼ぶ。1 つの IP アドレスから 1 分に 300 回までなので、1 回の更新で扱えるのは 7,500 行まで。超えると更新が失敗するので、1 分おいてからもう一度「すべて更新」を押す。

結果を公開するときは、出典として「アドレス・ベース・レジストリ（デジタル庁）」などを表示する。表示する出典の一覧は API のレスポンスの `source.attribution` にある。
