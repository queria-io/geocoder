# Google スプレッドシート

[`geocode.gs`](geocode.gs) は Apps Script のカスタム関数 `GEOCODE` で、住所のセル範囲を渡すと、行ごとに緯度・経度と地域コードを返す。

## 使い方

1. スプレッドシートの「拡張機能」→「Apps Script」を開く
2. [`geocode.gs`](geocode.gs) の中身を貼り付けて保存する
3. 結果を出したいセルに `=GEOCODE(A2:A100)` と書く。初回は外部への接続の許可を求められる

## 結果

範囲の行ごとに、次の 7 列を返す。行の順は渡した範囲と同じ。

| 列 | 内容 |
|---|---|
| 1 | 緯度 |
| 2 | 経度 |
| 3 | 照合レベル（`rsdtdsp_rsdt` は号、`rsdtdsp_blk` は街区、`parcel` は地番、`machiaza` は町字、`city` は市区町村） |
| 4 | 市区町村コード（5 桁） |
| 5 | 町字 ID |
| 6 | 郵便番号（7 桁） |
| 7 | 国勢調査の小地域コード |

- 空のセルと、照合できない住所の行は空になる
- 市区町村名のない住所で、同じ町名の市区町村が複数あるときは、先頭の候補（番地まで照合できた候補、次に人口の多い市区町村）を返す

## 回数の上限と時間

API を 25 行ずつまとめて呼ぶ。1 つのセルずつ `=GEOCODE(A2)` と書くと 1 行ごとに 1 回呼ぶので、範囲をまとめて渡す。

- 1 つの IP アドレスから 1 分に 300 回まで。Apps Script は Google のサーバーから呼ぶので、ほかの利用者と上限を分け合うことがある
- カスタム関数は 30 秒で打ち切られる。数千行を一度に渡して打ち切られるときは、範囲を分けて書く

結果を公開するときは、出典として「アドレス・ベース・レジストリ（デジタル庁）」などを表示する。表示する出典の一覧は API のレスポンスの `source.attribution` にある。
